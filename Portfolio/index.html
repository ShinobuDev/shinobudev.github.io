01 / Profil

Curieux,
autonome,
obstiné.

Je suis Adrien Robin, 21 ans, étudiant en BTS SIO option SISR en alternance chez SOLIHA Caen. Après un BUT Informatique et une Licence LLCER non poursuivis, j'ai recentré mon parcours sur ce qui m'animait depuis le collège : comprendre comment les machines communiquent.

Mon quotidien d'alternant alterne entre support utilisateurs (helpdesk téléphonique et terrain) et projets d'infrastructure (virtualisation Proxmox, services réseau, déploiement). Ces deux ans m'ont beaucoup appris sur l'écoute, l'accompagnement et la pédagogie au quotidien. C'est cette dimension humaine que je veux désormais mettre au cœur de mon métier : après le BTS, je me dirige vers l'assistance d'éducation.

B3 + B4 + B6 · Logiciel métier

RA-PRO

Logiciel de rapprochement bancaire conçu et développé pour SOLIHA Caen. Outil open-source en Python avec interface graphique, packagé en exécutable Windows pour un déploiement sans dépendance.

Python 3.11TkinterPandas PyInstallerGit
Repo GitHub →

Projet personnel mené pour répondre à un besoin réel de l'entreprise : automatiser le rapprochement entre les écritures bancaires et la comptabilité interne. Pensé pour être simple à installer, à configurer, et utilisable par un non-développeur.

  • Analyse du besoin métier avec l'équipe comptable de SOLIHA
  • Conception d'une CLI puis d'une interface graphique avec Tkinter
  • Traitement de fichiers Excel / CSV via Pandas
  • Génération automatique d'un fichier de résultat dans le dossier source
  • Packaging en .exe avec PyInstaller — déploiement sans Python
  • Code publié en open-source sur GitHub avec README, SECURITY et roadmap
